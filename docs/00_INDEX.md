# docs — Index

The documentation root. Each entry below is a one-line note on *why the
file exists*, not what it contains. Subdirectories carry their own
`00_INDEX.md`.

The manifesto supersedes everything else here; if a doc and the manifesto
disagree, the manifesto wins.

## Files

- [`MANIFESTO.md`](MANIFESTO.md) — the vision authority that guards
  against scope drift; read first.
- [`STATUS.md`](STATUS.md) — the resumption brief for picking the project
  back up; updated each session.
- [`architecture.md`](architecture.md) — captures the *why* behind subtle
  mechanism choices in shipped code, so the rationale outlives memory.
- [`art-wishlist.md`](art-wishlist.md) — the standing list of asset asks
  and conventions for contributing artists.
- [`code-cleanup-plan.md`](code-cleanup-plan.md) — the refactoring queue
  for aligning shipped code with the coding standards.
- [`F2-lod-seam-options.md`](F2-lod-seam-options.md) — scratchpad of
  candidate fixes for the LOD-boundary seam-crack problem.

## Subdirectories

- [`completed/`](completed/00_INDEX.md) — per-chapter records of work
  already shipped.
- [`diagrams/`](diagrams/00_INDEX.md) — visual maps of how the systems fit
  together.
- [`roadmap/`](roadmap/00_INDEX.md) — the vision / design / implementation /
  reference planning corpus.
