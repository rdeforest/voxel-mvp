# v1.0: Will People Pay For It On Steam?

> **Contradictions open:** "not a commercial endeavor" and Steam matchmaking
> conflict with current decisions. See
> [`../../reference/12-known-contradictions.md`](../../reference/12-known-contradictions.md) (C1, C3).

**Goal:** Open-source release with Steam value-added features.
**Status:** Pending; after v0.9.

The manifesto names this project as "not a commercial endeavor." That
remains true here. Steam is a distribution channel; it's not a profit
motive. Open-source release of the game code is the principal
commitment; Steam provides cloud saves, achievements, and matchmaking
infrastructure that's expensive to replicate.
