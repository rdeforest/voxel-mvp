# v0.2: Can I Make It Pretty?

**Goal:** Visual polish + the visual-fidelity items that don't gate
gameplay. Plus the first vehicle and the first non-SDF channel.
**Status:** Pending; after v0.5.

This is also where the DC-QEF transition most likely lands. See
[`14-dc-qef-transition.md`](../done/14-dc-qef-transition.md) for the work plan.
The transition is independent of the art tasks below and can be
sequenced before, after, or interleaved depending on momentum.

## Visual identity

- **FEAT051** ([#102](https://github.com/rdeforest/voxel-mvp/issues/102)): Visual identity pass — establish look distinct from
  Valheim/Enshrouded.
- **FEAT052** ([#103](https://github.com/rdeforest/voxel-mvp/issues/103)): Terrain textures — replace procedural shader with hand-
  painted grass / dirt / stone / sand / snow, plus normal maps.
- **FEAT053** ([#104](https://github.com/rdeforest/voxel-mvp/issues/104)): Triplanar texturing + moss/snow accumulation — slope-/
  altitude-driven blending.
- **FEAT054** ([#105](https://github.com/rdeforest/voxel-mvp/issues/105)): Building piece models — replace procedural box meshes
  with hand-modelled parts (wood grain, stone chiselling, metal
  forging).
- **FEAT055** ([#106](https://github.com/rdeforest/voxel-mvp/issues/106)): Tree/vegetation wind shader — animate scattered
  MultiMesh leaves.
- **FEAT056** ([#107](https://github.com/rdeforest/voxel-mvp/issues/107)): Water shader — reflections, shoreline foam.
- **FEAT057** ([#108](https://github.com/rdeforest/voxel-mvp/issues/108)): Lighting + atmosphere per biome — fog colour, sun
  angle.
- **FEAT058** ([#109](https://github.com/rdeforest/voxel-mvp/issues/109)): Sky — painted skydome, weather variants, clouds, sun/
  moon discs.

## VFX + audio

- **FEAT059** ([#110](https://github.com/rdeforest/voxel-mvp/issues/110)): VFX pass — dig dust, fill spray, flatten chips, strain
  crumble, collapse burst, part-break splinters, wind leaves.
- **FEAT060** ([#111](https://github.com/rdeforest/voxel-mvp/issues/111)): Sound design — footsteps per material, tool sounds,
  ambient by biome, structural creaks, collapse impact.
- **FEAT061** ([#112](https://github.com/rdeforest/voxel-mvp/issues/112)): UI overhaul — proper menus, settings screens, polished
  HUD.

## First vehicle + first non-SDF channel

- **FEAT062** ([#113](https://github.com/rdeforest/voxel-mvp/issues/113)): Phase 5.5d Multi-grid foundation — first vehicle
  prototype (cart or rowboat). The locomotive is firmly v0.9.
- **FEAT063** ([#114](https://github.com/rdeforest/voxel-mvp/issues/114)): Phase 5.5e Per-channel non-SDF data — initial channels
  (probably temperature + a simple wind vector field for atmospheric
  effects).
